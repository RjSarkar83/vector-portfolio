# AV Multicolour Brand Update

This update replaces the old red / black / white brand system with the current multicolour system.

## What changed
- **Palette:** coral, teal, mustard, navy, soft grey, white. Flat vector, no gradients, no text in base artwork.
- **Mockups:** 174 mockups in 23 categories (`assets/mockups/`, manifest in `js/mockups-data.js`).
- **Logo lockups:** centred icon on each blank branded panel, sized at about 50% of the panel. Horizontal panels carry the "ArtViSiON" wordmark.
- **Eyes:** white eyes with black pupils. Pupils follow the pointer, including over the mockup thumbnails and the popup. Eyes blink every 4.6 s.
- **Patterns:** three theme patterns in `patterns/` (infinity repeat, symbol mix, gear grid).
- **Site UI:** the AV LOGO badges and the "Open" overlay are removed. The Full Pack ZIP button is now "Try Now".
- **Removed:** blob motion from branding spaces. The old red brand rules are superseded.

## Deploy
1. Copy the update into the repo (see UPDATE-INSTRUCTIONS.txt).
2. Commit and push (manual step).
3. Replace the Full Pack ZIP button target with the Try Now link (manual step on GitHub Pages).
4. Hard-refresh the live site after deploy.
